# Parlons! Französisch-Sprechtrainer

Statische Webseite ohne Installation oder Build-Schritt.

## Veröffentlichung
1. Neues Repository auf GitHub erstellen.
2. `index.html` hochladen.
3. Auf Vercel ein neues Projekt anlegen und das Repository importieren.
4. Framework-Preset: `Other`; Root Directory: `./`; danach `Deploy`.

## Updates
Die Datei `index.html` im selben GitHub-Repository aktualisieren. Vercel veröffentlicht Änderungen automatisch.

## Hinweis
Mikrofon-Spracherkennung benötigt einen kompatiblen Browser und eine Freigabe. Die lokale Speicherung des Fortschritts ist geräte- und browsergebunden.
